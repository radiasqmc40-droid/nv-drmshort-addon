# NV Drama Short 1.8.2

Nuvio addon for DramaExpress.

## Run
```bash
npm install
npm start
```

Requires Node.js 20+.

## Endpoints
- `/manifest.json`
- `/health`
- `/catalog/...`
- `/meta/...`
- `/stream/...`
- `/stream-debug/...`

Version is explicitly `1.8.2` in `package.json`, `server.js`, manifest, health response, and startup log.
